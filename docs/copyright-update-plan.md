Copyright Update Task
=====================

This task requires updating the copyright header on some but not all source files in this repository.

The copyright header is a block of comment text at the very top of source files.

Any Rust source file with a name ending in `.rs` should be considered for updating.

If the file has not been modified after commit 6cb5e85ca632005b5899fac5f57274be33e31c46 then it should keep its existing copyright header.

If the file has been modified after commit 6cb5e85ca632005b5899fac5f57274be33e31c46, then it should be updated to the following:

/*

 *
